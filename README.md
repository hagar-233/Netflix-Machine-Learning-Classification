# 🎬 Netflix Content Classification

A machine learning project that analyzes the Netflix dataset and builds classification models to predict content categories based on selected features.

## 📌 Project Overview
The goal of this project is to prepare the Netflix dataset, perform data preprocessing, and develop machine learning classification models to evaluate predictive performance.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📂 Workflow
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Results Comparison

## 🤖 Machine Learning
The project focuses on supervised classification using Scikit-learn. Different classification models were trained and evaluated using standard performance metrics.
